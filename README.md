# ControlisAI Homebrew Tap

Homebrew formulae for [ControlisAI](https://github.com/controlisai) tools.

## Install

```bash
brew tap controlisai/tap
brew install recall-mcp-gateway
```

## Packages

| Formula | Description |
|---------|-------------|
| [recall-mcp-gateway](https://github.com/controlisai/recall-mcp-gateway) | MCP governance gateway for AI agent tool calls |

## Update

```bash
brew update
brew upgrade recall-mcp-gateway
```
